如何新增文件

  1. 把 Markdown 檔案與其資源(圖片等)放進任一子資料夾。
  2. 在 index.html 的「收錄文件」區段加入 <a data-file="路徑/到/檔案.md">。
  3. 或直接以網址 hash 開啟:index.html#路徑/到/檔案.md。
