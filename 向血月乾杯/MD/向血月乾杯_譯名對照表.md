## 十、占位符／標記（原樣保留）

| 標記 | 意義 | 處理 |
|---|---|---|
| `{HO1}` `{HO2}` `{HO2前世}` | 名稱占位符 | **原樣保留不譯** |
| `〈技能A〉〈技能B〉` / `or` / `〈技能A+技能B〉` | 技能擲骰規則 | 依原式保留（可／擇一／組合） |
| `＜　＞`／`〈　〉`（技能・判定） | 技能、判定包覆 | 統一用 `〈〉` |
| `■` | 段落／場景標題 | 轉為 Markdown 標題層級 |
| `====` / `─…─` / `----` | 分隔線 | 視情況以 `---` 或標題取代，不留雜訊 |
| KP 情報字體段（地の文 vs KP 情報） | KP 專用資訊 | 以引言塊標示「KP 專用」；地の文照譯為敘述 |
| 6版→7版 頁碼（基本.pXXX／MM.pXXX） | 原樣 | 數字與 p 原樣 |
